## Cursor 文本里最需要截图的地方

按当前规则，最该拍的是这几类位置：

1. `Ribbon` 菜单路径明显影响找功能的位置。
2. 对话框里有勾选项、下拉项、格式选项。
3. 右键菜单里有“继续编号 / 重新开始编号”这类易错操作。
4. 页眉页脚编辑态、分节符、页码格式、打印预览这类论文高频卡点。
5. 邮件合并向导这类“必须按顺序点下去”的流程。

不必优先拍的地方：

1. 纯概念解释。
2. 已经有 SVG / 示意图就能说清的原理块。

## 统一拍摄规范

Cursor 文本里的统一规范，整理后是：

1. 统一使用 `Word 365 / Word 2021 Windows 中文版`。
2. 统一保留 Word 原生界面，不要大面积文字覆盖。
3. 图里重点只强调“按钮、菜单、对话框、勾选项、编辑态”。
4. 图注要能写清楚菜单路径，例如：`引用 -> 交叉引用`。
5. 先拍核心卡点，再补低优先级说明图。
6. 用户新要求：后续优先使用“整屏 / 整个 Word 窗口”方式拍摄，而不是只截局部弹窗。
